# Privacy Policy

**Last updated:** 2026-07-14

This application ("the App") is designed with user privacy as a core principle. The App does not collect personally identifiable information (PII). The limited data that is collected is strictly for stability and functionality. Furthermore, the App does not sell Advertisement IDs, nor does it engage in any kind of tracking or data monetization.

## Information We Collect

### Crash Data (Firebase Crashlytics)

The App uses **Firebase Crashlytics** to collect crash reports. Crash reports may include:

- Device model
- Operating system version
- Technical crash diagnostics

Crash reports **contain no PII**. They are used solely for identifying and fixing stability issues. The developer has no control over Crashlytics data, and it cannot be linked back to individual users.

### Mapbox Services

The App uses **Mapbox** for map rendering. Mapbox may collect usage or diagnostic data under its own policies. This data:

- Is processed and retained independently by Mapbox
- Is never stored or processed by the App
- Can be opted out of through Mapbox's own settings

### Location Permission

The App may request location access strictly with explicit user consent.
Location data:

- Is used only for map‑related features
- Is not stored, transmitted, or analyzed by the App
- Is not linked with any crash or analytics data

## Data Export and Backup

The App provides an option to export all app data to a new device (iOS or Android).
When using this feature:

- The user is solely responsible for how they transfer and handle the backup file
- The exported backup **is not encrypted**
- The App assumes the device is not rooted/jailbroken, and therefore all data inside the App's sandbox remains protected by the operating system

All other recorded data remains unencrypted within the device's sandbox unless exported by the user.

## How The Data is Used

Data collected through Crashlytics is used exclusively for:

- Diagnosing technical issues
- Improving stability and performance

No user behavior is tracked or analyzed except in the context of a crash report. The App does not track users, monetize data, or sell Advertisement IDs.

## Third‑Party Services

The App uses:

- **Firebase Crashlytics** (Google LLC)
- **Mapbox**

Users should review each service's own privacy policy for their independent data practices.

## GDPR Compliance

### Legal Basis and Data Control

The App does **not store personal data on any servers**. All data remains on the user's device.
Crashlytics data is anonymized and controlled entirely by Google, and the developer has no ability to identify, or delete it.
Mapbox usage data is controlled by Mapbox.

### User Rights

Under the GDPR, users in the European Union have rights regarding personal data **only if it is held by the App**.
Since the App does not store personal data:

- The developer cannot identify and therefore delete crash reports per user.
- Mapbox data: The App includes a default Mapbox info icon to access the Mapbox Privacy Policy link and a Mapbox Telemetry menu to control settings. The developer does not have any control over these settings; the user decides whether to share telemetry data or opt out.

For local data on the device, the user controls it entirely, including any exported backups.

### Data Transfers

Crash data is processed by Google on our behalf. These transfers comply with GDPR requirements through Google’s standard data privacy and security frameworks.

## Children's Privacy

The App is not directed toward children and collects no personal information from any user.

## Data Retention

Crash data is retained by Firebase according to its own retention schedule.
The App itself stores no retained analytics or tracking data.
